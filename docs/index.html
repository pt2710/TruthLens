TruthLens hosted beta

A local honesty layer for misleading video feeds.

TruthLens is a browser-extension and API initiative focused on misleading packaging: clickbait, fake-news-like framing, deceptive thumbnails, and AI-mass-produced noise. It works locally on top of what a platform already shows the individual user.

What TruthLens is

TruthLens scores video packaging, surfaces warnings, keeps a human review sheet close to the content, and can locally rerank a user’s feed so repeatedly problematic channels and patterns become less prominent.

What TruthLens is not

TruthLens does not control YouTube’s backend recommender. It does not claim automatic report submission today. The current reporting path is still explicitly human-initiated.

Why it exists

Misleading packaging gets rewarded when it drives curiosity clicks, repeat views, and synthetic volume. TruthLens exists to make that pattern less attractive and to make honest, transparent presentation more visible and easier to defend.

  • Reduce the payoff of clickbait and misleading framing.
  • Make repeated problem channels easier to demote locally.
  • Help people review what they are seeing before they report it.
  • Support better information quality and platform transparency.

What it tries to protect

TruthLens is not meant to flatten honest creativity. It explicitly tries to preserve legitimate music, art, satire, gaming, tutorials, and other transparent non-literal formats instead of treating them like cheap deception.

  • Music and artistic framing should not be punished for being stylized.
  • Satire should not be treated like literal news by default.
  • Gaming and walkthrough content should not be demoted for normal presentation patterns.

Current beta truth

  • The Chromium extension is the first supported external beta surface.
  • The API is hosted and benchmark-tracked through the committed repo truth surfaces.
  • TruthLens can score, explain, suggest review, and locally rerank feed cards.
  • Review sheets open only on explicit user action.

Reporting truth

A TruthLens-assisted report today is still a human report. TruthLens can draft reasoning and help route the flow, but it does not claim autonomous mass reporting in the current public repo truth.

What external readers should know

TruthLens is aimed at a world where misleading packaging, fake urgency, and synthetic content farms can dominate attention. The project tries to nudge the ecosystem in the opposite direction: less reward for deception, more reward for transparency.
