# Discussions Guide

GitHub Discussions are enabled for TruthLens and are the preferred place for:

- beta feedback and workflow questions
- Q&A and troubleshooting that is not a reproducible bug
- ideas and roadmap discussion
- ethics, policy, and governance conversations
- false positive / false negative discussion when you do not yet have a concrete reproduction

Use GitHub Issues for:

- reproducible bugs with clear steps
- concrete false positive / false negative reports with a URL (or a redacted description) and what you expected
- specific documentation fixes

Security concerns:

- do not open public issues or discussions for vulnerabilities or suspected secret exposure
- follow `SECURITY.md`

Privacy and safety:

- do not post personal data, private URLs, or access tokens
- use redacted wording for sensitive examples

Documentation policy:

- GitHub Wiki is intentionally disabled to avoid duplicate/stale docs
- canonical docs live in `README.md`, `docs/`, and GitHub Pages

Funding policy:

- GitHub Sponsorships are intentionally disabled for this repo
- do not add sponsor links or funding button configs unless maintainers explicitly adopt a funding policy
